ToothBuddy · Characters + UI · v2.1

Three character casts for ToothBuddy, one per reference style.

Same five-character lineup adapted to each design language: Buddy (lead tooth), Plaque (antagonist), Brush (sidekick), Wisdom (adult-mode molar), Foam (celebration / completion). Plus UI elements (button, card, tab bar) and a Brush-home mockup for each set. Pick the lane that feels right and I'll commit it to Theme.swift.

Set 02 · Lane: Geometric character system (Duolingo)

Duolingo-inspired — disciplined cartoon cast

Rules applied: 1–2 basic shapes per character, 5-style eye system (round / glasses / almond / linear / dots — no ovals), asymmetric mouth, flat saturated fills, 2px outline + 4px drop-shadow ("chunky outlined" — same trick Duolingo uses on every button). Cap height letterforms in Nunito ExtraBold (closest free fit to Duolingo's Feather Bold).

Set 01 · Lane: Editorial hand-drawn (Headspace)

Headspace-inspired — single-metaphor scenes

Rules applied: organic blob shapes, no outlines (or very thin), warm saturated fills, intentionally "imperfect" curves, faces simplified to two dots and a curve. Each illustration carries one metaphor (jog / sleep / hug). UI recedes; illustrations occupy ~40% of any key screen. Headline font is Fraunces italic for warmth.

Set 03 · Lane: Companion + room (Finch)

Finch-inspired — Buddy lives in a mouth-shaped room

Rules applied: single companion that grows and dresses up, pastel-on-pastel palette, room-as-screen metaphor (the home tab is literally Buddy's pink-tiled bathroom), affirmation language ("send a high-five" not "tap like"). Poppins rounded for UI. This is the biggest commit — it changes the information architecture, not just the visuals.

How to pick

Reply with one of:

  • 02 — Duolingo geometric cast. Smallest IA change (just visuals + new mascots). Safest port to current SwiftUI.
