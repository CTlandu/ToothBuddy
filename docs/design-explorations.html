ToothBuddy · Visual Identity

Four design language directions for the rebuild.

Each phone below renders the same screen (the "Brush" home tab) so you can compare apples-to-apples. Pick the direction that feels closest, or mark two and tell me which axis to blend — palette of A, type of B, etc. Once we agree, I'll port the tokens to Theme.swift and update every screen.

Shared decisions across all four: iOS 16+ SwiftUI, custom tab bar (already shipped), kid- and adult-mode share the same core (palette and density flex per mode), local-only data (no progress imagery that implies cloud).

Maximum Apple-native vibe. Every surface is a frosted glass card floating over an aurora background; the gradient itself is the brand. Strong on iOS 17/18 thanks to native .ultraThinMaterial and .regularMaterial. Risk: depth-heavy designs age fast if Apple shifts. Best fit if the goal is "feels expensive, feels new."

How to pick: tell me a number (1–4), or two numbers like "3 structure, 2 palette". I'll then propose a single concrete Theme.swift token table and migrate one screen end-to-end so you can compare in the real app before we commit.

  • All four assume the existing tab order (History · Brush · Family · Tips) and the existing custom tab bar.
  • None require new app capabilities — pure visual / typographic / token swap.
  • Kid mode vs adult mode is handled per-direction via density + accent shifts, not by switching design languages.
